START HERE

从首次运行，到可重复评测。

01 本机运行

Python 3.10+，启动 python3 server.py 后用 Chrome / Edge 打开 localhost。模型与 WASM 都在仓库内，基础检测不依赖外网。

加载失败可改为强制 CPU 后重新加载。浏览器显示实际使用的推理后端。

02 验证闭环

采集或导入样本 → 查看疑点和证据 → 保存报告 → 人工标注 → 查看效果评测。相同样本重复测试应按模型、规则版本分别统计。

03 可选视觉模型

在 config/development.local.json 配置地址、模型名和密钥，重启后可对当前报告发送证据。每次发送需要勾选授权。

纹身、疤痕、发色仅支持模型观察；缺少服务时明确显示未评估。

04 数据和限制

仅点击保存才落盘，原视频不保存。数据目录按开发、测试、生产区分。生产配置仍是单机工作台，不提供公网多用户服务。

项目完整文档见仓库 README.md 和 docs/。没有内置真实缺失样本，也没有已验证的准确率。
