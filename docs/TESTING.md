# 软件测试与人工验收

## 自动测试

```bash
python3 scripts/verify.py
```

需要 Python 3.10+ 与 Node 20+，无 pip/npm 依赖安装。测试使用临时数据库，不修改日常数据。

单独运行：

```bash
python3 scripts/doctor.py
python3 -m unittest discover -s tests -v
node --test tests/domain.test.js
```

doctor 校验配置和模型 SHA-256。Python 测试覆盖实际 HTTP、保存、标注历史、评测公式、模型输出校验、私有目录不可访问。Node 测试覆盖空目标、几何边界、帧覆盖率、仲裁、动作保持/超时。

GitHub Actions 在 Linux、Windows、macOS 运行同样的软件检查。此 CI 不启用真实摄像头，不下载受试者样本，不计算模型准确率。

## 浏览器验收

启动隔离的测试环境：

```bash
python3 server.py --env test --port 8001
```

用 Chrome / Edge 打开 http://localhost:8001，按下表记录操作与结果。可用 Playwright CLI 自动执行，自动化结果须标明模拟输入和实际输入。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| CPU 无 GPU 路径 | 强制 CPU → 加载模型 | 人体 CPU、手部 CPU，按钮可用 |
| GPU / 回退 | 自动 → 加载模型 | 显示各模型实际使用的后端 |
| 空白自检 | 样本回放 → 自检 | 肢体/手指 uncertain，不误判完整 |
| 图片文件 | 导入 samples/blank.png，授权，分析 | 解码与真实模型推理成功，无目标为 uncertain |
| 视频回放 | 导入授权视频，查看抽帧 | 有时间点、帧数不超过配置上限 |
| 批量输入 | 图片和视频混选，含坏文件 | 正常文件完成，坏文件报错，后续继续 |
| 取消 | 视频分析时停止后续分析 | 保留部分结果、取消标记，未完成不判清晰正常 |
| 保存 | 勾选授权 → 保存 → 刷新页面 | 报告仍在列表，证据可读 |
| 幂等保存 | 同一 run_id 重复请求 | 不增加第二条 |
| 标注 | 填人工标签、人员、数据集 → 保存 | 评测对应分母更新，旧标签留历史 |
| 模拟排除 | 保存并标注空白自检 | 模拟记录不进入准确率 |
| 模型不可用 | 默认配置 | 复核按钮不可用，基础检测可用 |
| 复核失败 | 测试接口错误/超时/非法 JSON | 明确报错，本地结果保留 |
| 摄像头拒绝 | 拒绝授权 | 显示恢复提示，不死锁 |
| 采集中断 | 采集中结束或设备断开 | 释放摄像头，中断步骤清晰标记 |
| 超时与跳过 | 不完成动作或跳过 | 不能得到“全部正常”结论 |
| 重新检测 | 结束后再次开始 | 新基准、新动作状态、新 run_id |
| 小屏 | 390px 宽窗口 | 单列布局，操作可触达，表格横向滚动 |
| 导出与打印 | JSON、CSV、JSONL、打印 | 下载合法内容，打印仅报告 |

## 回归要求

发现 bug 先添加最小失败测试；无法自动化时记录输入、步骤、预期和实际，再修复。改模型或阈值不仅跑软件测试，还要用固定真实验证集记录新旧指标及失败样本。

## 必须人工完成的效果验收

真人动作、真实缺失、不同设备/光照、美甲类型、真实大模型延迟和判断。当前无这些资源，交付记录中必须写未验证，不能用空白图、假摄像头或 mock 输出替代。
