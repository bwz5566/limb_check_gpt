## 本轮修复并复测

- 摄像头授权后无首帧导致无限等待：增加授权/播放超时和迟到流释放；浏览器复测恢复成功。
- SQLite 事务上下文未显式关闭连接：改成始终关闭连接的上下文管理器，避免 Windows 文件锁问题；失败测试转为通过。
- 并发点击保存同一报告：改成数据库唯一键上的原子插入，24 个重复请求返回同一报告 ID。
- 报告集合字段类型不足：增加限制，防止保存后报告无法渲染。
- 视觉模型附带未请求字段：白名单输出，避免写入额外观察属性。
- 默认前三张证据可能漏掉手背：优先手背、掌心、站立，并允许用户选择 1–3 张复核证据。
- 首次 Windows CI 检出 Git 自动换行导致第三方 JS 哈希不一致：通过 `.gitattributes` 固定资源原始字节，保留严格哈希校验。
