# 用户操作手册

## 首次准备

1. 安装 Python 3.10+，确认 `python3 --version`（Windows 使用 `py -3 --version`）。
2. 克隆仓库，运行 `python3 scripts/doctor.py`；所有模型资源应显示 OK。
3. 运行 `python3 server.py`，浏览器打开 http://localhost:8000。
4. 点击加载模型。自动模式先尝试 GPU，创建失败才回退 CPU；页面分别显示人体、手部实际后端。
5. 无 GPU 或驱动异常时选择强制 CPU。第一次推理可能比后续推理慢。

普通启动没有安装依赖的步骤。摄像头、浏览器语音和硬件驱动属于设备能力。离线使用可关闭语音，避免操作系统语音服务的网络行为。

## 实时检测

- 上肢与手部：站立 → 侧平举 → 上举 → 掌心 → 手背 → 握拳 → 张开 → 随机手势。
- 全身与手部：增加左右抬腿、下蹲和恢复站立。
- 手部专项：跳过全身动作。

摄像头固定，先保证头脚入框；手部步骤走近镜头。尽量保持光线均匀，不用极端逆光。动作满足条件后连续保持默认 1 秒自动前进；一般步骤 25 秒超时，随机手势 10 秒超时。

超时或跳过不是“肢体异常”的证据，会在报告记录未完成并要求复核。不能完成动作时可以跳过，不要求用户强行做动作。手背通过与掌心方向变化辅助确认；左右手识别不稳定时可能需要调整或跳过。

点击结束将停止摄像头并产生中断报告。切换工作区不会自动停止正在进行的采集，结束采集后再处理其他样本。刷新页面会丢失未保存报告。

## 图片与视频

进入样本回放，选择一张或多张图片/视频，勾选使用授权后开始分析。支持常见 PNG/JPEG/WebP 和浏览器可解码的视频；推荐 H.264 MP4。单文件上限 250 MB，图片上限 4000 万像素。

勾选“手背朝前”才启用美甲色差。不要对掌心、握拳、全身远景开启该项。这个勾选是输入前提，并非模型确认了手背。

视频按时长计算抽帧数量，最多 60 帧，超过上限时均匀覆盖全片而非只分析开头。报告中保留实际时间点与采样信息。视频回放不执行引导动作状态机，不会判断“已完成一整套动作”。

对于模拟或合成输入，勾选“模拟 / 合成样本”，以排除效果统计。文件报告记录 SHA-256，便于确认版本对比时输入一致。

取消会停止后续帧和后续文件，已产生的部分报告保留并标明取消。某个文件解码失败不阻止后续文件。

## 结果阅读

| 状态 | 含义 |
| --- | --- |
| 未见规则疑点 clear | 当前可观察内容未触发阈值，不代表身体完整或适岗 |
| 发现疑点 flag | 触发规则或视觉模型观察到疑点，需要查看证据 |
| 无法判断 uncertain | 遮挡、质量不足、动作未完成或模型分歧 |
| 未评估 not_assessed | 未启用、不适用或没有对应能力 |

“手指五根关键点”不等于“真实存在五根完整手指”。侧身和透视可能造成长度比异常。美甲色差不能可靠检测透明甲、裸色甲。外观项只记录、未做本场景效果评测。

## 保存、标注与评测

1. 查看报告与证据，点击导出 JSON 可保存到浏览器下载目录。
2. 勾选本地保存授权，点击保存报告。原视频不保存，报告包含最多 6 张截图。
3. 在人工标注区逐项填写真实标签，标注人必填。未检查的项目保持未标注。
4. 数据集建议使用 `validation-v1` 等固定名称，受试者 ID 使用匿名编码。
5. 打开效果评测，用数据集和版本筛选；无分母的指标显示 —。
6. 可在报告列表导出 CSV 和 JSONL；JSONL 不含图片和逐帧明细，完整备份使用备份脚本。

标注可以修正，最新版本用于评测，旧版本保存在 annotation_history 表。重复点击保存同一 run_id 不会重复插入；重新分析相同文件会产生新 run_id，统计时按记录计数。

## 可选大模型

配置完成并重启服务后，报告下方复核按钮可用。在证据区勾选 1–3 张图片（默认优先手背、掌心、站立），再勾选发送授权后调用。模型输出严格校验，低置信度转为无法判断；与本地状态不同也要求人工复核。已保存的原报告不被覆盖，复核结果作为新版本另存。

无接口时基础流程照常可用。接口失败不会清空本地结果。模型名称、提示词版本和输出保留在报告中，但 API 密钥不进入报告。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 模型加载失败 | 不要 file:// 打开；运行 doctor；强制 CPU；检查浏览器控制台 |
| 摄像头不可用 | localhost 地址、浏览器权限、系统权限、是否被其他软件占用 |
| 推理卡顿 | CPU 推理在主线程执行；降低摄像头分辨率或调整 inferenceIntervalMs；避免开多个检测标签页 |
| 总是无法判断 | 检查入框、光照、手掌像素尺寸、是否存在多人；不要盲目降低阈值 |
| 视频打不开 | 换 H.264 MP4；检查文件大小；浏览器编码支持因系统而异 |
| 保存失败 | 磁盘空间、目录写权限、报告过大、是否勾选授权；刷新页面后重试 |
| 评测为空 | 是否保存且标注了真实样本；模拟样本会排除；过滤条件是否正确 |
| 端口占用 | 使用 `--port 8010` 并访问对应地址 |
